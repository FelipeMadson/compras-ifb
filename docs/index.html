Engenharia de Software

Arquitetura em Camadas Desacoplada

Camada 01

Domínio Puro

Independência absoluta de UI e frameworks. Entidade imutável com copyWith e regras de validação testáveis com Dart puro.

  • Item: Entidade imutável com rastreio de sincronização.
  • ItemRepository: Contrato abstrato (DIP).
  • Regras: Validação de tamanho [2, 40] e restrição [1, 99].
Camada 02

Dados e Persistência

SQLite relacional atômico no aparelho, concorrência otimista via timestamps e resiliência com jitter.

  • SQLite: Tabela com chave primária e CHECK.
  • Concorrência: Verificação condicional em atualizado_em.
  • Nova Tentativa: Exponential backoff com full jitter.
Camada 03

Apresentação & Estado

Composition Root com Riverpod, rotas declarativas e canal de plataforma Kotlin nativo.

  • Riverpod: AsyncNotifier com reatividade seletiva.
  • Deep Linking: Esquema compras://app/item/:id.
  • Platform Channel: Bateria, modelo e OS via Kotlin.
Persistência Relacional

Esquema SQLite e Integridade

Em substituição ao shared_preferences, a tabela relacional assegura isolamento atômico, índice dedicado para consultas de sincronização e integridade por restrição CHECK em nível de engine.

CREATE TABLE itens ( id INTEGER PRIMARY KEY AUTOINCREMENT, nome TEXT NOT NULL, quantidade INTEGER NOT NULL CHECK (quantidade BETWEEN 1 AND 99), categoria TEXT NOT NULL, observacao TEXT NOT NULL DEFAULT '', comprado INTEGER NOT NULL DEFAULT 0, sincronizado INTEGER NOT NULL DEFAULT 0, criado_em INTEGER NOT NULL, atualizado_em INTEGER NOT NULL ); CREATE INDEX idx_itens_sincronizado ON itens (sincronizado);
Qualidade e Verificação

Suíte de Testes Automatizados

Unidade (Domínio)

regras_item_test.dart

Validações de nome, cardinalidade [1, 99], ordenação semântica e métricas consolidadas.

Unidade (Dados)

nova_tentativa_test.dart

Verificação de repetição diante de FalhaTransitoria até o sucesso ou teto máximo com jitter.

Integração (SQLite)

item_repository_sqlite_test.dart

Testes sobre motor SQLite real em memória (FFI) sem emulador: inserção, exclusão e bloqueio otimista.
