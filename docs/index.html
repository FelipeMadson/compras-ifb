Lista de Compras Móvel com SQLite e Arquitetura em Camadas

Implementação integral e resiliente do tutorial da Aula 15 da disciplina de Desenvolvimento para Dispositivos Móveis. Engenharia orientada a offline-first, separação estrita de responsabilidades, inversão de controle via Riverpod e canal de plataforma nativo em Kotlin.

Engenharia de Software

Arquitetura em Camadas Desacoplada

Camada 01

Domínio Puro

Isolamento de qualquer biblioteca de interface ou banco. Entidades imutáveis com copyWith e regras de validação puras testadas com Dart puro.

  • Item: Entidade imutável com rastreio de sincronização.
  • ItemRepository: Contrato abstrato (DIP).
  • Regras: Validação de tamanho [2, 40] e restrição [1, 99].
Camada 02

Dados e Persistência

SQLite relacional no aparelho, mapeador de registros e concorrência otimista com validação por timestamp.

  • BancoDeDados: Abertura singleton e metadados.
  • Concorrência: Bloqueio otimista via atualizado_em.
  • Resiliência: Backoff exponencial com full jitter.
Camada 03

Apresentação & Estado

Composition Root centralizado com Riverpod. Gerenciamento de ciclo de vida assíncrono via AsyncValue e roteamento com GoRouter.

  • Providers: Injeção sem geração de código.
  • Deep Linking: Esquema compras://app/item/:id.
  • Acessibilidade: WCAG, Semantics e Breakpoints M3.
Camada Relacional

Esquema do Banco SQLite e Concorrência

Em substituição ao shared_preferences, a tabela relacional assegura atomicidade de transações, consultas indexadas por registros pendentes e restrição no motor via CHECK como defesa em profundidade.

CREATE TABLE itens ( id INTEGER PRIMARY KEY AUTOINCREMENT, nome TEXT NOT NULL, quantidade INTEGER NOT NULL CHECK (quantidade BETWEEN 1 AND 99), categoria TEXT NOT NULL, observacao TEXT NOT NULL DEFAULT '', comprado INTEGER NOT NULL DEFAULT 0, sincronizado INTEGER NOT NULL DEFAULT 0, criado_em INTEGER NOT NULL, atualizado_em INTEGER NOT NULL ); CREATE INDEX idx_itens_sincronizado ON itens (sincronizado);

Instalação e Teste no Android

# 1. Compilação do APK de Produção (Universal) flutter build apk --release # 2. Instalação Direta via ADB no Aparelho ou Emulador adb install -r build/app/outputs/flutter-apk/app-release.apk # 3. Teste de Abertura por Ligação Profunda (Deep Link) adb shell am start -W -a android.intent.action.VIEW -d "compras://app/item/1" br.edu.ifb.felipemadison.compras
