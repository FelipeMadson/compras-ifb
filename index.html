Persistência Relacional

Esquema Estruturado do Banco SQLite Local

🗄️

Tabela canônica: itens_compra

Armazenamento local auditável com restrições de integridade, chaves tipadas e carimbos de data/hora ISO-8601 UTC.

CREATE TABLE itens_compra ( id INTEGER PRIMARY KEY AUTOINCREMENT, nome TEXT NOT NULL, categoria TEXT NOT NULL, quantidade INTEGER NOT NULL CHECK (quantidade > 0), comprado INTEGER NOT NULL DEFAULT 0 CHECK (comprado IN (0, 1)), observacao TEXT NOT NULL DEFAULT '', criado_em TEXT NOT NULL, atualizado_em TEXT NOT NULL, sincronizado INTEGER NOT NULL DEFAULT 0 CHECK (sincronizado IN (0, 1)) ); CREATE INDEX idx_itens_compra_comprado ON itens_compra (comprado, nome);
